I · The Problem

Are you still fighting raw MISMO XML?

MISMO 3.x is a huge, deeply nested, attribute-heavy XML standard. Generic parsers quietly destroy the data that matters most.

Pain — what generic parsers do

  • Money silently mangled: 240000.00 → 240000, 9.0000 → 9 — a single truncated amount is a compliance breach.
  • Padded identifiers destroyed: 000123 becomes 123, breaking loan and MERS references.
  • The classic XML-to-JSON trap: DEAL_SET is an object today, an array tomorrow — DEAL_SET[0] crashes in production.
  • Re-exporting is impossible: duplicate <?xml> declarations, lost attributes, entity-escaping drift.
  • Hand-rolled traversal code for every new file shape. Forever.

Desire — what you actually want

  • Every amount, rate, and ID preserved exactly as written — verified, not assumed.
  • Predictable arrays for every known MISMO collection container, out of the box.
  • Attributes, namespaces, and XLink relationships intact and queryable.
  • Lossless round-trip: parse → edit → compose → well-formed, valid XML.
  • One tiny script tag in the browser, zero build step, zero dependencies.

III · Method

Simple steps to success

Three methods. No config, no schema download, no build step.

Step 1

Parse — XML → clean JSON

Read any MISMO 3.x payload into a predictable object tree. Values stay exact strings — 240000.00, 000123, and true survive untouched.

const json = engine.parse(xml);
Step 2

Explore — relationships & structure

XLink RELATIONSHIP entries are indexed automatically. Traverse the graph with getLinkedEntities() to follow a borrower to their loan to their appraisals.

engine.getLinkedEntities(ref);
Step 3

Compose — JSON → well-formed XML

Serialize your tree back to MISMO XML: exactly one declaration, attributes intact, entities escaped — output you can hand back to a GSE or servicer.

const out = engine.compose(json);

Why this approach is different, and why it works

Most "MISMO helpers" are wrappers around a generic XML parser with default coercion on — which is precisely what mangles money and padded IDs. MISMO.js flips every coercion off, hard-codes the MISMO collection grammar (39 array containers), indexes XLinks, and guards compose output. Every release is verified against the official UCD v2.0 samples plus public third-party MISMO files before it ships.

V · Common Questions

MISMO.js — frequently asked questions

Straight answers for developers evaluating MISMO.js.

What is MISMO.js?

MISMO.js is a zero-dependency JavaScript library for parsing, transforming, and generating MISMO 3.x mortgage XML. It runs in the browser via a plain <script> tag and in Node.js via ESM or UMD imports, with no runtime dependencies.

Does MISMO.js lose money amounts or padded identifiers?

No. MISMO.js disables numeric coercion entirely, so values like 240000.00, 9.0000, and 000123 round-trip exactly as strings. An automated suite verifies 100% of leaf values and attributes survive round-trip across 13 real MISMO files (~956 KB).

Can I use MISMO.js without a build step?

Yes. Drop one <script> tag into an HTML page and window.MismoJS is ready — no npm, no bundler, no build. The live demo on this page runs exactly that way. ESM and UMD builds are also included for bundlers and Node.

Which MISMO versions are supported?

MISMO.js targets the MISMO 3.x line (3.3, 3.4, and the GSE UCD v2.0 / ULAD-based files used in production). Any well-formed MISMO XML document is accepted, so newer 3.x releases generally parse without changes.

How do I export well-formed MISMO XML?

Call engine.compose(parsed) with the object returned by engine.parse(xml). Output contains exactly one <?xml> declaration, preserves attributes, and is XML-validated by the test suite on every release.

Is MISMO.js free to use?

Yes. MISMO.js is free and open source on GitHub — no license keys, no accounts, no telemetry. Found a parsing bug? File an issue with sanitized example XML and it will be added to the fidelity regression suite.
